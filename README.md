# Food Ordering System

A web-based Food Ordering System developed using PHP, HTML, CSS, JavaScript, and MySQL.

## Features
- User Registration & Login
- Food Menu Display
- Add to Cart
- Checkout System
- Admin Panel
- Database Connectivity

## Technologies Used
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- XAMPP

## Execution Process

### Step 1: Install XAMPP
Download and install XAMPP server.

### Step 2: Start Apache and MySQL
Open XAMPP Control Panel and start:
- Apache
- MySQL

### Step 3: Move Project Folder
Copy the project folder into:
C:\xampp\htdocs\

### Step 4: Create Database
- Open phpMyAdmin
- Create a database named:
food_ordering_system

### Step 5: Import SQL File
Import the SQL database file into phpMyAdmin.

### Step 6: Run the Project
Open browser and enter:
http://localhost/food_ordering_system/

### Step 7: Access Admin Panel
Admin panel URL:
http://localhost/food_ordering_system/admin/
